`subjects_test.txt` — 15 предметов оплаты с ожидаемыми ответами PASS / FAIL / EDGE
(формат: `предмет | ОЖИДАНИЕ`). EDGE — спорные кейсы, допускается любой ответ,
но уверенность должна быть ниже, чем на однозначных.
